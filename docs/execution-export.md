# 目标与执行导出

进入“目标与执行 → 目标 → 项目 → 任务”，点击“新建目标”旁的“导出”。

- 当前筛选结果：使用场景、目标周期、状态、搜索和待完善筛选，包含必要的上级路径，并注明“上级路径”。
- 全部目标项目任务：忽略当前筛选，导出当前档案全部目标、项目和任务。
- 已勾选目标及全部下级：先在目标树勾选目标，再选择此范围；包含子目标、子项目和任务，不受筛选及折叠影响。

选择 Markdown（`.md`）或可编辑的 Word（`.docx`）后点击“导出文件”。文件名包含北京时间，保留多级层级、场景、状态、编号、日期、说明、衡量标准、里程碑和预计投入等已有内容。独立项目和任务单列，空值标为未设置或未填写，不补造内容。

生成在浏览器本地进行，不修改业务记录、不调用 AI。下载的文件可能包含个人规划内容，请妥善保存。此功能用于阅读和编辑规划；可恢复的数据备份仍使用“导出完整备份”。
