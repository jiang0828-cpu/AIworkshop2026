# 认识自己：轻量闭环

四个页签保持不变。每页有一句用途说明和可展开的填写示例，按当前需要填写即可。

## 使用方法

1. **个人档案**：在重要经历下点击“沉淀为能力证据”，检查预填内容后保存。
2. **我的愿景**：点击“安排第一步”，填写行动与完成标准；日期、目标、项目可选。
3. **我的能力**：填写能力证据及下一步，点击“安排练习”。自评可留空，已有评分保留。
4. **资源**：资源、约束及待验证假设均可“安排使用／验证”；也可以选择已有行动。

已有未完成行动时主按钮变为“继续行动”。展开“行动与复盘”可查看全部关联行动、状态以及“更新进度”。完成行动后填写两项简短复盘：实际结果（必填）、下次调整（可选）。每日协同已有结果可以直接引用。

保存复盘后选择“补充能力证据”“更新原记录”或“暂不更新”。草稿确认后才回写，重复确认会打开已有结果。原记录在草稿打开后发生变化时会拒绝覆盖，重新打开草稿即可。

更新原记录针对：愿景的期望状态、能力的待提升项、经历的学习收获、证据／假设的证据内容、资源／约束的说明。其他字段继续通过原有编辑入口修改。评分不会随行动结果自动变化。

## 数据与兼容

- 使用同一条 Action；工作台、认识自己和每日协同共用，不建立第二份任务。
- 新表 `SelfActionReview` 以 Profile 与行动 ID 唯一保存结果、调整、暂缓状态及回写结果。来源关联复用 `RecordSource`。
- `/api/strategy` 新增 `self-link`、`self-review`、`self-apply`。创建及回写使用现有数据库锁和原子事务／D1 batch。
- AI 行动必须先验收并确认同步完成；普通行动接口和复盘接口都校验这一要求。
- 删除来源保留行动、复盘及历史关联；行动页显示来源已删除。删除行动保留复盘，但不能继续回写。
- 完整备份与同步包含复盘。个人档案备份只包含档案、证据、愿景和技能，不包含行动、复盘及行动来源关联。旧备份未提供复盘字段时按空集合兼容。

## 本地迁移和运行

```powershell
npm run db:migrate:self
npx prisma generate --generator client
npm run dev -- --hostname 0.0.0.0 --port 3012
npm run daily:worker
```

迁移脚本先使用 `VACUUM INTO` 备份 SQLite，再执行 `0005_self_loop.sql`；已迁移时跳过。Windows 更新 Prisma Client 前需停止占用原生引擎的本地预览和调度器，生成后再启动。本次实际工作库已备份并迁移，预览与调度器已恢复。

Cloudflare 使用相同的 `0005_self_loop.sql` 增量迁移。生产发布时必须先备份远端数据库并迁移，再发布应用和调度器；本次不执行远端迁移或部署。
