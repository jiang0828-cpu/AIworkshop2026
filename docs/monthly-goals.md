# 复盘中的月目标

任务与复盘顶部共用周／月切换。月复盘模式展示月目标及月复盘，周复盘模式展示周目标及周复盘。

点击新增月目标，沿用目标表单，预填本月周期、当前上海日期所在月的月末截止日期和当前场景；可调整截止日期、指标、状态和关联愿景。历史本月周期目标同样显示，列表按场景筛选，不创建独立目标库。

保存后可编辑或点击查看项目与任务，进入目标与执行的同一条目标。目标周期筛选新增本月；月目标可分解为本周子目标。原90天目标默认分解路径保留。

数据库使用原Goal模型，无迁移；完整备份及同步复用原目标记录。
