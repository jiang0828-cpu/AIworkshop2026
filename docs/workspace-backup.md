# 完整工作台备份

- 任意页面右上角的下载按钮可导出完整备份。
- “设置 → 完整工作台备份”提供导出、最近导出记录和恢复入口。
- 文件名为 `ai-workbench-backup-YYYYMMDD-HHmmss.json`，使用北京时间。
- 建议每周、批量修改或迁移前导出，保留多个日期的文件，并另存一份到可信的离线介质。
- 最近导出记录仅保存在当前浏览器，表示已发起下载，不代表浏览器已将文件写入磁盘。

## 范围

包含当前 Profile 的基础档案、经历、能力证据、价值观、资源、约束、假设、场景、总愿景与场景愿景、历史版本、研判与研究记录、执行规划、目标与关系、项目与里程碑、行动、周期规则、复盘、来源关系、今日置顶、AI 偏好、上下文包、AI 任务与反馈、修正记录、档案文档、每日计划、Agent、工具与技能配置、步骤、执行记录、计时和日报。

不包含环境变量、API 密钥、访问密码、程序代码、浏览器设置、服务运行状态，也不下载外部链接指向的文件。导出文件含个人业务资料，应妥善保管。

## 恢复

选择同一完整工作台格式的 JSON，确认后覆盖当前业务数据。旧版备份继续兼容；单模块导出文件不能作为完整备份恢复。

恢复前先导出当前备份。运行中的任务会阻止覆盖恢复，需先结束执行；恢复的排队或运行任务暂停，待人工重新启动。数据恢复不替代服务端环境配置。

本次不增加数据库表，不需要数据迁移，不改变现有同步格式，也不自动执行恢复、定时下载或生产部署。

## 隔离恢复演练

在 PowerShell 中设置本地备份路径后运行以下命令。测试创建临时 SQLite 数据库，验证恢复及主要记录数量，结束后删除测试数据库，不连接实际业务库。

```powershell
$env:WORKSPACE_BACKUP_FILE = 'E:\path\to\ai-workbench-backup-YYYYMMDD-HHmmss.json'
npx vitest run src/lib/daily/integration.test.ts -t '真实完整备份可恢复'
Remove-Item Env:WORKSPACE_BACKUP_FILE
```
