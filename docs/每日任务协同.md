# 每日任务协同

## 本地运行

```powershell
npm run db:migrate
npm run dev
```

在第二个终端启动后台调度进程：

```powershell
npm run daily:worker
```

前端和调度器使用同一个 `.env` 和 SQLite 数据库。调度器运行时，关闭浏览器不会停止 AI 任务；关闭调度器或关机后，队列保留。过期的执行会标记为失败，需要确认后手动重试。不能通过关闭网页停止上游模型请求。

Windows 上更新数据库前先停止同目录的 Web 服务和调度器，再执行 `db:migrate`，避免已加载的 Prisma DLL 被锁定。如果只有 schema 变化且当前 Prisma Client 已生成，可使用 `npx prisma db push --skip-generate` 完成数据库同步。

`AI_API_KEY`、`AI_BASE_URL`、`AI_MODEL` 沿用现有配置；每个 Agent 可单独覆盖模型。凭证只存储在服务端配置中。编排未配置 AI 或失败时回退规则；执行阶段不会伪造结果或回退为完成。

## 使用与状态

在“行动与复盘”下方打开“每日任务协同”，输入待办并编排。确认草稿前可以修改任务分类、步骤、执行人、预计分钟、截止时间与检查点。确认保存后点击启动，任务按步骤顺序执行，不同任务的 AI 步骤最多并发 3 个。

人工步骤保存开始、暂停、继续的计时区间。AI 步骤返回结果后进入待验收，验收通过才推进下一步；退回要求会加入下一次输入。混合任务中的人工步骤需要手动启动，后续 AI 步骤在前一步完成后自动排队。

默认写作、编码建议和资料整理 Agent 均只有文本模型能力，没有真实联网、代码执行、文件写入或消息发送权限。每次调用只带当前任务资料和同一任务已经验收的前序步骤结果。Agent 配置修改只影响之后创建的执行，不改写运行中的快照。

标记阻塞会停止人工计时、撤销尚未开始的 AI 调用；已经发送到模型的请求无法保证取消，其结果不会再回写步骤。执行槽位保留到调用结束或租约到期，防止取消后产生额外并发。

导入已有行动按当天去重。完成每日任务不会自动更改周行动，需点击“同步行动完成”。任务日期和输入的时间均按北京时间处理，未明确的截止时间留空。

## 日报与数据

后台每天北京时间 22:00 为已有计划生成日报，恢复运行时补生成遗漏日期。报告为生成时快照，后续完成任务可手动刷新，已有人工复盘保留。自动报告只使用数据库数字和模板，不额外消耗模型 token。

完成率包含当日所有任务，只有全部步骤完成才算完成。准时率仅统计已到截止时间或已完成、且有截止时间的任务。效率得分按完成率 60%、准时率 25%、未阻塞比例 15% 加权；无适用准时率时归一化剩余权重，无任务时不评分。人工投入累计计时区间，AI 耗时累计实际请求时间；平均完成投入只统计已完成任务。token 缺失显示未知。

模块支持 JSON 导入导出和 Markdown 日报导出，也纳入档案中心的完整备份与既有本地到云端同步。导入替换数据；有执行中任务时拒绝导入。恢复的排队、执行中和准备中状态转为暂停，开放计时区间冻结于备份时间，必须手动重新启动。旧版完整备份不含协同字段时，协同数据恢复为空。云端沿用已有 D1 备份恢复方式：完整预校验后按依赖顺序恢复，不支持 Prisma 交互式事务；导入前应先保留备份。

## Cloudflare 部署

先备份线上数据，然后运行增量迁移和构建：

```powershell
npm run cf:d1:migrate
npm run cf:build
npm run cf:daily:check
```

`0003_daily_collaboration.sql` 只新增协同表，不修改原有表。Web Worker 和调度 Worker 共用 `ai-workbench-data` D1。为两个 Worker 分别配置同一个 AI 凭证；现有 Web Worker 的认证 secrets 保持原配置。

```powershell
npx wrangler secret put AI_API_KEY
npx wrangler secret put AI_API_KEY --config cloudflare/daily-wrangler.jsonc
npm run cf:deploy
npm run cf:daily:deploy
```

调度 Worker 每分钟触发，无公开 HTTP 执行入口。模型请求默认 120 秒超时，可在 Agent 中设置 30–120 秒。数据库原子领取保留最多 3 个并发槽位，执行租约 180 秒；租约过期后人工重试，晚到响应不能覆盖新结果。Cloudflare 定时触发配置传播可能需要一段时间，首次上线后检查界面后台心跳与 Worker 日志。

## 验证

```powershell
npm run typecheck
npm run lint
npm test
npm run build
npm run cf:build
npm run cf:daily:check
```

新增测试使用临时 SQLite 数据库和模拟模型响应，不修改用户数据库，不访问真实 AI 服务。生产发布命令需在部署阶段执行；构建和 dry-run 不会部署。
