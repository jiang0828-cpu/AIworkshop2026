# 项目任务与周／月／年复盘

入口：`/?section=actions&tab=yearly`。页签为“周计划与复盘、月计划与复盘、年计划与复盘”，各页签只展示两个主区块：当周计划／上周总结、当月计划／上月总结、当年计划／去年总结。计划区包含可展开的周期目标，以及项目任务和新建入口；总结区显示上期交付事项、复盘和折叠的其他周期记录。

周期按上海日期计算，周一至周日、自然月、自然年。目标按 `deadline`、任务按 `dueDate` 落入当期；项目按自身 `deadline`、里程碑的 `deadline` 或关联任务的 `dueDate` 归入周期。当期任务完成数只计算当期截止的任务。未排期、未来或更早到期的事项保留在目标与执行，不自动补日期，不按完成时间或标题猜测。

模块入口、项目旁的周／月／年快捷入口及周期页签默认进入今天所属的周期，不沿用项目交付日期或之前选择的历史日期。手动选择计划日期后可查看对应历史周期，刷新和浏览器返回保留该日期；“回到当前”恢复今天。

上期交付事项显示上期里程碑与到期任务，包括未完成事项和独立任务。同时纳入上期实际完成的行动与每日工作；只记录了独立每日工作也可填写复盘。新增任务默认截止日期为当期末，用户可调整。新复盘预填上期范围和来源；表单仍可调整项目、任务、每日工作及日期。已有上期复盘时直接编辑；历史记录可继续查看、编辑与删除。

表单展示所选任务的当前状态、完成标准及完成数量，保存成果、问题和下一周期调整。复盘不会自动修改任务状态。已关联的项目、任务可以从历史复盘直接打开；来源被删除后保留原名称。原周目标、月目标及年度目标放在可展开区域，继续使用同一目标数据。

## 自动填充与手工维护

计划区自动汇总当期交付项目与任务，上期总结区自动汇总上期交付事项和实际完成工作。填写总结时自动生成可编辑草稿：项目与日期、当前已完成任务、每日实际结果、未完成事项及待安排清单。不推测完成原因，不把完成标准当作实际成果，也不自动安排下一期日期。

草稿使用现有 `Review` 字段；确认保存前不创建记录。调整所选项目任务时，只更新尚未手动改写的自动内容，手动文字和主动清空的字段保留。“按项目任务填充”可重新生成；替换手写内容前需确认，取消则保留原文。已有总结默认保持已保存内容，生成文本不超过 API 每字段 5000 字限制，较多条目通过关联记录继续查看。

计划与总结两侧均可新建、查看、编辑、删除原项目和任务，操作沿用 `/api/data`，不会复制独立计划任务。新增交付日期默认是对应当期或上期的结束日，可修改；删除沿用原记录删除确认。已保存总结可查看问题与原因、编辑及删除，来源删除后仍保留总结快照。

## 数据兼容

- 复用 `Review` 和 `RecordSource`，无新增数据库字段或迁移。
- 新建复盘由 `/api/data` 校验项目与任务归属，复盘和关联原子保存；修改关联时替换，避免重复。删除复盘仅清理它的来源关联，不删除项目任务。
- 旧复盘不自动补关联，仍可查看与编辑原文；可手动补充关联。已删除来源的历史复盘仍可修改文字。
- 完整备份、同步沿用现有复盘和来源关联结构；个人档案备份不复制业务记录。Markdown 包含周／月／年标签和所关联项目任务名称。
- 周复盘提醒只统计周复盘，不会因保存月复盘或年复盘而误认为本周已复盘。

## 每日完成工作

- 周／月／年总结同时展示应交付事项与实际完成工作，按场景分组、展开与折叠，并响应场景筛选。
- 实际完成以 `completedAt` 的上海日期归期，不使用每日计划日期、交付日期或最后修改时间。普通行动须已完成；每日任务须存在执行步骤且全部验收完成。待验收 AI 结果不纳入。
- 以原行动 ID 合并项目任务和每日执行；多次执行保留各次日期与结果。独立每日任务以自身 ID 去重，同名不同记录均保留，未确认回写的每日执行不会改变原行动状态。
- 复盘可选择项目、行动或独立每日完成工作，保存为现有 `RecordSource`；日常来源使用 `dailyTask` 类型。完整备份与同步恢复这些来源，Markdown 导出保留来源名称；来源删除仍保留总结正文和名称快照。无需迁移。
- 已有手写总结保持原文；新的每日结果只在创建或主动重新填充草稿时整理，可筛选后编辑再保存。
