# 周期任务与每日、周报计划

- 目标与执行中的周期任务复用同一 Action，每日执行复用现有 DailyTask，不创建新的任务库，无数据库迁移。
- 起点采用上海时区的任务创建日期。每日每天执行；每周沿用创建日的星期；每月沿用创建日的日期，月份不足时取月末。交付日期是重复安排的结束日期，包含当天；未设置时持续重复。
- 每日协同的待确认清单优先填入当日周期任务，继续支持移出、修改和手动确认编排，每批最多 20 项。未来到期的周期任务也可进入当天清单。不会自动保存或启动 AI。
- 每条 Action 每天最多一条每日执行记录，本次截止默认为当天 23:59:59。周/月任务仅在重复日提供本次执行，历史日期可在日期选择中查看。
- 完成本次步骤、验收以及确认同步，保留本次执行结果和同步记录；周期主任务继续有效，不把它改为已完成。手动将主任务完成、取消或归档可终止后续安排。
- 周、月、年计划按实际重复日期列入任务及其所属项目，每项周期任务显示应执行次数和每日执行记录中的已完成次数。未执行、排队及待验收都不计为完成；复盘草稿沿用相同统计。普通任务继续按截止日期归入计划。
- 所有数据继续使用现有完整备份及每日协同备份；不修改历史数据、不自动执行远端部署。

注意：旧记录没有独立的周期起始时间，统一采用原创建日。修改重复频率后，历史计划按当前频率展示，已经保存的日报与人工复盘文本保持原样。
