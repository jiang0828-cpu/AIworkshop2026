# 五模块重构说明

## 简化版界面（2026-10-02）

- 工作台以今日优先、状态和任务列表为主；场景概览、关联提醒、动态及 AI 协作默认收起。
- 认识自己去掉重复标题，档案默认展开基础信息，其余分组按需展开；访谈和导入导出合并到档案工具区。
- 形势研判保留“研判记录／历史”，类型和场景使用紧凑筛选；统计与日期核验按需展开。
- 决策中心默认进入“我的决策”，愿景为第二页签，协同和对齐检查收进辅助入口；详情只展示已填写内容。
- 项目详情直接展示项目和行动，不重复目标详情及项目看板；风险、里程碑、AI 任务和文档按需展开。

本轮只调整界面呈现，无数据库迁移。TypeScript、ESLint 和 Playwright 的 1440／390／320px 五模块共 15 项页面检查通过，覆盖折叠展开、默认页签和手机返回，无运行错误或页面横向溢出。

## 模块与流程

工作台保留统一任务列表、看板、搜索、步骤进度及去重，增加四场景概览、三项今日优先、集中未分类入口和可打开原记录的近期动态。今日置顶按上海日期保存，完成任务退出推荐。未关联任务保留未分类。

认识自己提供个人档案、价值与愿景、优势与技能、资源与约束。愿景在此编辑、归档和查看版本；技能评估引用原能力证据。档案记录支持多个场景，不选时保留全局适用。

形势研判提供环境概览、趋势与事件、机会与威胁、竞争／标杆、变化日志。原本周态势、企业／个人影响及自由文本保留；新研判区分事实与判断，保存来源、核验、影响、应对与比较信息。原态势每次保存也生成快照。

决策中心提供愿景引用、目标协同矩阵、重大决策、对齐检查。冲突对称、依赖有方向，禁止自关联；对齐只展示实际缺项与已记录冲突。决策选项支持收益、成本、风险、可逆性及结果复盘。创建目标／项目先编辑草稿，确认后保存来源，可沿关联双向打开。

目标与项目保留时间层级、父子目标、分解、投入、边界、风险与停止条件，连贯展示目标、项目、里程碑及行动。行动完成率和里程碑进度分别显示。项目可直接新建行动、加入每日计划、预填 AI 任务、保存项目文档。加入每日计划不会自动启动，沿用人工验收和确认回写。

场景、页签、记录及目标／项目关联通过 URL 保存。桌面使用列表与详情区域，手机长详情使用抽屉。编辑离开提供保存、放弃和继续编辑；保存失败保留表单。

## 数据与接口

- 固定四个场景槽位：职业、财务、家庭、健康。允许改名和排序，ID 保持稳定，没有单独删除接口。
- 新增 `WorkbenchScene`、`StrategyRecord`、`StrategyVersion`、`GoalRelation`、`RecordSource`、`WorkbenchPin`、`GoalBatch`。
- 愿景、技能、结构化研判、档案场景标签和旧态势快照使用分别经 Zod 校验的结构。版本保存完整快照。
- 目标、项目新增可选 `sceneId`／`visionId`；决策新增可选场景、愿景、研判和目标关联。历史 ID、字段和状态保留，不自动归类。
- `/api/data` 扩展读取及字段白名单；档案字段与标签、业务创建与来源在同一事务保存。
- `/api/strategy` 处理场景、记录、关系、批量归类、分析草稿和幂等分解；`/api/situation` 使用同一处理逻辑。
- `/api/workbench-focus` 保存最多三项当天置顶，校验任务及 Profile 归属。
- 本地使用 Prisma 事务；D1 使用参数绑定 SQL 的原子 batch。备份恢复失败整体回滚。

所有新关联校验当前 Profile，跨场景项目必须明确确认。愿景通过归档保留引用；已删除来源显示相应提示，来源关联不会级联删除业务记录。

## AI 与备份

分析和分解先预览选定资料。默认遮挡未授权敏感内容，场景改名不改变敏感场景过滤；联系方式和证件号脱敏。人工确认后才调用现有服务端模型，返回值经校验进入可编辑草稿，采用和保存再次由用户确认。失败保留手动流程，不自动联网或执行。

完整备份、个人档案备份和同步已扩展；旧备份可缺少 `strategy`。个人档案恢复按固定槽位映射场景，并保留目标标签；完整恢复保留新增关联。运行中的协同任务阻止覆盖导入。队列恢复继续采用既有暂停及人工重新启动规则。

新生成的 Markdown、身份卡和上下文包可引用愿景、研判及技能，并沿用敏感授权。历史文档内容、身份卡版本和上下文快照不会因新增模块被重新生成。

## 本地运行与迁移

要求 Node.js 24，使用当前 `.env` 中的 SQLite 路径。服务端密钥保持环境变量／Worker secrets，不写入业务日志或浏览器。

已有数据库执行增量迁移：

```powershell
npm run db:migrate:strategy
```

命令先创建一致的 SQLite 备份，再原子执行 `cloudflare/migrations/0004_five_modules.sql`，已迁移时跳过。若数据库不存在，先运行 `npm run db:migrate`。原有 `db:migrate` 也增加了迁移前备份。当前工作数据库已经完成迁移，原始备份位于 `data/ai-workbench-before-five-modules.db`。

启动页面和既有后台调度进程，分别运行：

```powershell
npm run dev -- --hostname 0.0.0.0 --port 3012
npm run daily:worker
```

当前预览使用 `.next-daily-dev`，构建使用独立目录以避免干扰。关闭浏览器不停止后台调度；关闭调度进程则无法领取新 AI 步骤。
