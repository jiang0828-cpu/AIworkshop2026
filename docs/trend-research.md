# 形势研判：外部环境雷达

## 当前流程

五个页签共用一条关联链：信息采集 → 信息分析 → 形势判断 → 决策应变 → 反馈验证。

1. 新增关注主题（可选），填写问题、场景、信息维度与复查日期。
2. 收集资料，或记录一张手动信息卡。正文、事实摘录与个人备注分开；未知发布日期留空。只有链接时先保存，选择信息卡后提取网页；提取失败可编辑并粘贴正文。
3. 勾选最多15张信息卡，手动分析或 AI 辅助分析。AI 发送前选择个人背景并预览；敏感背景逐次授权。检索仅收到去标识化的公开检索词。
4. 编辑分析稿，确认研判。研判保存为不可覆盖的版本；修订生成新版本，既有应变与验证仍引用原版本。
5. 低置信度可以安排核实／观察任务；正式应变要求人工确认、中／高置信度及依据，资料不足或分歧不能直接执行应变。确认只创建或关联原模块决策／行动，不自动调整目标、项目、资源或执行止损。
6. 回到研判卡记录实际走势，分别评价判断和措施效果。经验先保存规则草稿，填写适用条件与例外后确认入库；可修订、停用。
7. 在反馈验证页按上海时区生成周／月／季／年报告。摘要最多5条，详情保留完整期间引用及遗留事项，支持 Markdown 导出，不再限制最近100批次。

目标详情的“参考研判”和复盘记录中的“外部判断验证”关联具体判断版本，不复制正文。所有新研判保存和关联入口只保存本地，不调用远端同步。

桌面使用列表与详情双栏，手机使用详情抽屉。页签、场景、主题、状态、分页与记录 ID 保存在 URL；刷新和浏览器返回可恢复位置。取消、版本冲突与服务失败保留编辑输入。

## 数据与迁移

沿用项目 StrategyRecord 的记录容器模式，新增 RadarRecord 表，按 kind 独立持久化主题、信息、分析稿、研判、判断版本、应变、验证、规则、报告、后台任务映射、跨模块引用和只读历史。所有引用校验当前 Profile。

ResearchBatch 仅承担持久化队列与调用日志。收集阶段不调用模型；分析结果发布为草稿，不自动成为已确认判断。来源内容、个人背景和引用保存独立快照；信息修改创建新记录，避免历史证据漂移。

增量 SQL：cloudflare/migrations/0010_external_radar.sql，同时适用 SQLite 和 D1。
本地执行：

```powershell
# 先停止本项目网页和调度进程，避免 Windows Prisma DLL 锁定。
npx prisma generate --generator client
npm run db:migrate:radar
```

迁移脚本先使用 VACUUM INTO 备份本地 SQLite，再创建表和稳定映射。联网来源、结论、反馈及已有行动／决策关联不重复创建；旧简表与难以拆分的自由文本保留只读历史材料。迁移可重跑。原始记录和历史版本不覆盖。

本地已生成备份：data/ai-workbench.db.before-radar-1791130750627.db。首次映射2条历史材料；实际业务量以本地数据库为准。没有执行远端迁移、同步或部署。

完整备份及手动同步包含 radar 字段。模块 JSON 仅恢复研判记录与研究队列，不复制已有行动／决策；个人档案备份不含外部研判资料。恢复前校验记录、来源、引用及 Profile；运行中拒绝覆盖，恢复的排队／执行任务暂停为失败状态，等待人工重试。旧备份缺少新字段时走同一历史转换逻辑。

## 配置与启动

密钥仅放在本地环境变量或 Worker secrets，不能写入前端、日志和备份：

```dotenv
AI_API_KEY=模型密钥
AI_BASE_URL=https://api.deepseek.com/v1
AI_MODEL=deepseek-reasoner
TAVILY_API_KEY=Tavily密钥
```

```powershell
$env:NEXT_DIST_DIR='.next-daily-dev'
npm run dev -- --hostname 0.0.0.0 --port 3012
# 另开终端，持续运行：
npm run daily:worker
```

研究任务串行领取，租约180秒，搜索／提取45秒、模型120秒；调用阶段与用量独立保存，Token 缺失显示未知。中断后人工重试复用已保存资料，不静默重复计费；晚到结果不能覆盖新执行。关闭页面不影响后台，关闭电脑／调度器会中断。后台任务区域显示配置、状态、调用日志和心跳。

未配置 Tavily 时保留手动正文与人工分析，明确拒绝联网请求。已有模型配置不等于具有搜索能力。医疗模板只预填检索问题，可改为其他行业，不硬编码个人经营路径。所有检索、分析、更新和报告均由用户点击启动；到期仅在页面提示。

URL 仅支持公开 HTTP(S)。拒绝本机、私网、凭证、自定义端口和非公开 DNS 地址；只通过固定 Tavily 提取接口获取正文，不直接跟随用户 URL，返回地址必须匹配请求。正文截取16000字符，不保存完整 HTML。外部正文是资料，不是指令；模型只能引用实际来源编号与可核对摘录，不能生成验证历史或确认规则。

## Cloudflare

网页与定时 Worker 共用现有 D1，分别配置模型和 Tavily secrets。定时 Worker 继续通过 Scheduled Handler 调度，不增加自动搜索或订阅。
本地可执行 npm run cf:build 与 npm run cf:daily:check 验证打包；后者为 dry-run。远端迁移、部署及同步必须另行取得用户确认，本次未执行。
