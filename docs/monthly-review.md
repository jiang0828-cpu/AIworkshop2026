# 月复盘

任务与复盘的复盘区域支持周／月切换。选择月复盘，点击“填写本月复盘”，选择月份后记录本月收获、目标／策略／执行／外部条件问题及下月调整；历史记录支持编辑和删除。

月复盘以完整自然月日期区间保存，周复盘沿用已有日期区间；整月记录归入月复盘，其余历史记录保留在周复盘。无需新增数据库字段或迁移，完整备份、同步和Markdown导出继续复用原有复盘数据。月复盘不会替代工作台的周复盘提醒。

默认月份和本周日期使用Asia/Shanghai；月末包含闰年2月和跨年边界。服务端拒绝缺失、无效或倒置日期。
