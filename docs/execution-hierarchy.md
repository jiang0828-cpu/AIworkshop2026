# 目标、项目与任务多级从属

- 目标保留原有多级结构和时间跨度规则。
- 项目可包含子项目，任务可包含子任务，没有固定层数配置。
- 展开项目后可新增子项目；任务右侧加号可新增子任务。编辑表单可选择上级或解除从属。
- 父子项目属于同一目标；父子任务属于同一项目和目标。新建子项预填所属关系，移动存在下级的记录需先处理不一致的下级。
- 状态独立保存，完成子项不会自动完成父项。项目显示项目内任务实际完成数量，不包含子项目任务，不把结构层级当作完成进度。
- 删除父项保留子项，只解除父子关系；原有目标、项目关联及执行历史继续保留。
- 搜索和筛选保留完整上级路径，记录只展示一次。深层结构在窄屏限制缩进，保持文字可读。

## 数据迁移

本地执行 `npm run db:migrate:hierarchy`，自动先用 SQLite `VACUUM INTO` 生成备份，再增量加入 `Project.parentId`、`Action.parentId` 和索引。再次执行不会重复添加字段。随后执行 `npx prisma generate` 和 `node scripts/generate-prisma-models.cjs`，并重启本地服务。

Cloudflare D1 对应 `cloudflare/migrations/0013_execution_hierarchy.sql`。远端须在发布新代码前单独执行迁移，本次未操作远端数据库或生产部署。

完整 JSON 备份和同步保留父子关系，恢复时按父项在前排序，拒绝循环和无效上级；旧备份缺少新字段时恢复为顶层记录。个人档案备份继续不包含执行项目和任务。Markdown 导出增加从属路径，历史文档和 AI 上下文快照保持不变。
