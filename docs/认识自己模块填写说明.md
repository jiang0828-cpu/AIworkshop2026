# “认识自己”模块填写说明

> 用途：把对自己的模糊感受，整理成可以回看、补充、验证和用于行动决策的结构化资料。
>
> 使用原则：先记录事实，再写自己的判断；先允许不完整，再通过经历、行动和复盘逐步修正。所有字段都可以后续修改，不要求一次填写完毕。

## 一、建议填写顺序

建议按下面的顺序完成，不必一次写完：

1. 先填写“基础信息”和“当前身份”，建立当前生活与工作的基本坐标。
2. 再填写“人生阶段”和“现实情况”，说明你现在为什么处在这个位置，以及有哪些真实边界。
3. 记录 3～5 条“重要经历”，优先选择对你产生长期影响的经历。
4. 从经历中提炼“能力与证据”，每项能力都尽量配一条可验证证据。
5. 填写“核心价值与取舍规则”，说明什么对你重要，以及发生冲突时如何选择。
6. 补充“资源”和“约束”，让目标和行动方案建立在现实基础上。
7. 将还不能确定的判断放进“待验证假设”，避免把猜测误当成事实。

首次填写完成后，进入“目标与项目”把认识转化为 90 天目标；再在“行动与复盘”中用实际行动验证这些判断。每周复盘一次，必要时回来修改本模块。

## 二、基础档案

### 1. 基础信息

这一组内容用于建立个人概况，帮助你和 AI 区分“我是谁”与“我正在做什么”。只填写对长期协作有帮助的信息，不需要填写联系方式、精确住址、证件号码或账户信息。

| 字段 | 内容意义 | 填写说明 |
| --- | --- | --- |
| 怎么称呼你 | 确定日常沟通中的称呼 | 填写你希望工作台或 AI 使用的称呼，也可以填昵称。 |
| 年龄段 | 提供大致人生阶段背景 | 选择最接近的区间即可；不希望提供时选择“不便说明”。 |
| 出生年份（可选） | 在需要时辅助判断时间跨度 | 非必填。只填写年份，不填写完整出生日期。 |
| 性别称谓 | 确定称呼和表达方式 | 填写你接受的称谓；不需要说明与任务无关的身份信息。 |
| 常驻城市 | 说明时区、环境和生活条件 | 填城市或地区即可，不填写街道、门牌等精确地址。 |
| 最高学历 | 提供教育背景的概况 | 填学历层级即可；不必填写学校名称，除非它对当前目标有直接帮助。 |
| 专业背景 | 说明长期学习和知识积累 | 填专业、研究方向、培训经历或长期积累的领域。可以写多个，用逗号或分号分隔。 |

**填写示例**：

```text
专业背景：医学相关领域、市场管理、产品策划；近一年开始系统学习 AI 工具。
```

### 2. 当前身份

这一组内容描述你现在在社会、职业和组织中的位置。它不是简历，而是为了回答：“我目前承担什么责任，正在用什么能力解决什么问题？”

| 字段 | 内容意义 | 填写说明 |
| --- | --- | --- |
| 行业 | 说明你所处的业务或专业环境 | 填行业名称或领域，例如医疗科技、教育、制造、咨询。 |
| 公司 / 组织 | 说明当前所属组织 | 可填写组织名称或组织类型。该字段为敏感字段，默认不发送给 AI。只有明确允许后才会进入相关上下文。 |
| 职业状态 | 标记当前主要工作状态 | 从选项中选择最接近的一项。状态变化后及时更新。 |
| 岗位 / 职业身份 | 说明你当前的职业位置 | 用别人容易理解的名称描述，例如产品负责人、研究者、自由职业者。 |
| 主要角色 | 说明你同时承担的角色 | 可填写多个角色，例如管理者、专业人员、照护者、学习者。建议按当前重要程度排序。 |
| 当前职责 | 说明你正在对谁负责、交付什么 | 写清楚主要对象、主要工作和预期价值。尽量使用动词和结果，而不是只写职位名称。 |
| 专业方向 | 说明希望持续积累的方向 | 填未来一段时间想建立优势、持续投入或形成作品的领域。 |

**推荐句式**：

```text
我目前是【身份】，主要为【对象】负责【职责】，希望在【方向】上形成【能力或成果】。
```

### 3. 人生阶段

这一组内容帮助你理解当前阶段的主题、变化来源和阶段性诉求。它不是给自己贴永久标签，而是记录“现在的我处在哪个阶段”。

| 字段 | 内容意义 | 填写说明 |
| --- | --- | --- |
| 当前人生阶段 | 概括当前阶段的主题 | 用阶段性语言描述，例如职业转换期、能力建立期、家庭责任增加期、重新寻找方向期。 |
| 阶段变化背景 | 解释为什么进入当前阶段 | 写发生了什么变化、何时开始变化，以及它对你产生了什么影响。 |
| 当前优先事项 | 明确近期必须优先保障的事情 | 建议列出 1～3 项，并区分“必须保障”和“希望推进”。 |
| 阶段诉求 | 表达这个阶段真正想获得的支持或成果 | 可以写希望获得的空间、资源、确定性、成长、收入、关系改善或生活安排。 |
| 当前困难 | 记录正在阻碍推进的问题 | 描述具体困难及其影响，不急于解释成个人能力不足。 |
| 未来 1-3 年方向 | 提供中期方向 | 写暂定方向即可，不要求做出不可改变的承诺。 |
| 成功状态的定义 | 把“成功”变成可观察状态 | 描述到达理想状态时，你的工作、生活、能力、关系或选择会有什么具体变化。 |

**好的填写方式**：

- “我现在处在职业方向重新选择期，优先确认适合长期投入的领域。”
- “如果这一阶段进展顺利，我会有稳定的现金流、可复用的专业能力，并能保留每周固定的个人时间。”

**避免这样填写**：

- 只写“迷茫”“压力大”“想变好”，但没有说明具体背景和希望变化。
- 把 AI 的推断或他人的评价直接写成自己的事实。

### 4. 现实情况

这一组内容用于提醒自己：任何目标都受到时间、精力、责任和风险承受能力的影响。现实条件不是借口，而是制定可执行方案的输入。

| 字段 | 内容意义 | 填写说明 |
| --- | --- | --- |
| 家庭责任 | 说明会影响时间和决策的照护或家庭安排 | 只写与计划安排有关的内容，例如固定照护时间、需要共同决策的事项。该字段敏感，默认不进入 AI。 |
| 健康 / 精力状态 | 说明可持续投入的状态 | 只记录与工作安排相关的精力和节奏，不填写诊断、病历或详细医疗信息。该字段敏感，默认不进入 AI。 |
| 收入范围 | 说明目标的财务背景 | 只填写区间，不填写银行卡、账户、资产明细或支付凭证。该字段敏感，默认不进入 AI。 |
| 财务压力 | 说明短期财务边界 | 可以写“需保障几个月现金流”“近期不适合承担大额固定成本”等主观判断。该字段敏感，默认不进入 AI。 |
| 行为模式 | 记录自己在压力、选择和合作中的惯性反应 | 用具体场景、行为和结果描述，例如“面对不确定任务会先收集资料，容易推迟开始”。 |
| 风险偏好 | 说明对不确定性和试错的接受程度 | 选择保守、平衡或激进。它是当前偏好，不是永久性格结论。 |

## 三、右侧结构化记录

### 1. 重要经历

**意义**：经历比抽象评价更能说明你如何行动、承担什么、学到了什么。它是后续提炼能力、识别价值和验证自我判断的重要证据来源。

**每条经历建议填写三部分**：

- **标题**：用“事件 + 结果”命名，例如“负责一次跨部门项目并按期交付”。
- **经历描述**：写背景、你的责任、采取的行动和结果。
- **我的收获**：写你确认学到的能力、偏好、边界或教训。

**优先记录这些经历**：

- 做成过且对现在仍有帮助的事情；
- 失败或受挫但改变了你判断方式的事情；
- 需要在价值冲突中做选择的事情；
- 能体现你长期重复模式的事情；
- 对职业、关系、生活方向产生明显影响的转折。

**推荐模板**：

```text
标题：在【背景】下完成【任务】
经历描述：当时的目标是【目标】，我负责【责任】，采取了【行动】，最后得到【结果】。
我的收获：我确认自己擅长 / 不擅长【内容】，以后会继续 / 避免【做法】。
```

不要只写“很辛苦”“很成功”，要尽量写清你做了什么、结果是什么、哪些内容可以被证据支持。

### 2. 能力与证据

**意义**：把“我觉得自己会什么”与“我有什么证据”分开，减少自我高估或低估，让目标和任务可以建立在已验证能力上。

**填写方法**：

1. 在“能力”中写一个具体能力，例如分析问题、推动协作、产品规划、表达复杂内容。
2. 在“证据”中写事实：完成过什么、产生了什么结果、谁可以验证、在什么条件下有效。
3. 用置信度表示当前把握程度；置信度低并不代表能力不存在，而是表示证据仍不足。

**证据优先级**：

- 可量化结果：按期交付、提升效率、完成收入或质量目标；
- 可重复行为：在多个场景持续表现出同一能力；
- 他人反馈：来自具体合作对象的反馈；
- 作品或记录：方案、报告、代码、课程、公开成果；
- 自我感受：可以记录，但应标为判断，不替代事实证据。

**避免填写**：

- “沟通能力强”“学习能力强”这类没有场景和结果的标签；
- 把一次偶然成功直接当成稳定能力；
- 把 AI 的评价或网络测试结果当作已确认事实。

### 3. 核心价值与取舍规则

**意义**：价值不是口号，而是在资源有限或目标冲突时，帮助你做选择的优先级和规则。

每条价值规则建议写清：

- **价值**：什么对你重要，例如自主、专业、稳定、创造、关系、成长、公平；
- **优先级**：当前阶段相对重要程度；
- **取舍规则**：两个价值冲突时，你通常如何选择；
- **冲突场景**：这个规则在哪些情况下会被挑战。

**推荐句式**：

```text
当【价值 A】与【价值 B】冲突时，我通常优先【选择】，前提是【边界】；如果【例外条件】出现，我会重新评估。
```

**示例**：

```text
价值：自主
取舍规则：在收入差距可控的情况下，优先选择能保留决策空间的方案；如果现金流低于安全线，先恢复稳定。
冲突：短期收入与长期自主性发生冲突时，需要结合财务压力重新判断。
```

### 4. 资源

**意义**：资源是你可以调用、组合或进一步建设的条件，帮助行动方案不只停留在愿望层面。

可以记录：

- 时间：每周可稳定投入的时间；
- 能力：已经掌握且能直接使用的能力；
- 人际与合作：可咨询、协作或获得反馈的人；
- 工具与资料：软件、设备、数据、作品和知识来源；
- 资金与空间：可投入的预算、场地或其他条件；
- 已有成果：可以复用的方案、流程、作品和经验。

写资源时说明“它能帮助我完成什么”，避免只列名词。

### 5. 约束

**意义**：约束是当前不能忽略的边界。它能帮助系统避免提出看似合理、实际无法执行的建议。

每条约束建议包含：

- 约束名称：时间、预算、精力、地域、组织流程等；
- 具体描述：它怎样限制行动；
- 严重程度：如果忽略会造成什么后果；
- 可变性：固定约束、短期约束，还是可以通过行动改善的约束。

**推荐句式**：

```text
约束：每周可投入时间有限。
描述：工作日只能安排零散时间，完整任务主要放在周末。
影响：不适合同时启动多个需要连续专注的项目。
```

### 6. 待验证假设

**意义**：把“可能是真的，但还没有足够证据”的判断单独保存，避免它悄悄变成身份标签、目标依据或 AI 事实。

**适合记录的内容**：

- “我可能更适合小团队，而不是大组织。”
- “如果减少并行任务，我的完成质量可能会提高。”
- “目标用户可能愿意为这个方案付费。”

每条假设最好补充：当前依据、验证方法、验证期限和状态。验证时使用实际行动、访谈、数据或复盘结果，不要只靠再次思考。

## 四、事实、判断与假设的区分

填写时可用下面的判断标准：

| 类型 | 含义 | 示例 |
| --- | --- | --- |
| 已知事实 | 有记录、结果或他人可验证的内容 | “过去三个月完成了两项交付。” |
| 用户判断 | 你对事实的解释 | “我在截止日期明确时执行得更好。” |
| 用户偏好 | 你希望怎样工作和生活 | “我偏好先看到结论，再看详细依据。” |
| 现实约束 | 当前必须考虑的边界 | “每周只有六小时可用于额外项目。” |
| AI 推断 | AI 根据资料提出的可能解释 | “可能存在任务切换过多的问题。” |
| 待验证假设 | 尚未被行动或证据确认的判断 | “减少并行任务后，完成率可能提高。” |

AI 推断和待验证假设不能直接替代已确认档案。发现不准确时，应修改原字段或将纠正内容作为新的确认记录处理。

## 五、隐私填写规则

建议只记录完成目标和行动所需的最小信息：

- 不填写密码、验证码、证件号码、银行卡、账户凭证和精确住址；
- 收入只写区间或财务压力，不写账户和资产明细；
- 健康只写对时间和精力安排有影响的情况，不写诊断和病历；
- 家庭责任只写对计划有影响的安排，不写他人的详细隐私；
- 公司 / 组织、家庭责任、健康 / 精力、收入和财务压力默认不发送给 AI；
- 只有在创建身份卡或上下文包时显式允许，相关字段才可能进入 AI 上下文；
- 发送前务必查看隐私预览，并逐项排除不必要内容。

## 六、填写完成后的闭环

完成“认识自己”不是终点，建议形成下面的循环：

```text
记录基础情况
    ↓
从经历提炼能力和价值
    ↓
区分事实、判断与待验证假设
    ↓
建立 90 天目标和项目
    ↓
拆成本周行动并执行
    ↓
周复盘：结果、策略、执行、外部条件
    ↓
用证据验证或修正原有判断
    ↓
回到“认识自己”更新档案
```

每次回到本模块时，只需回答三个问题：

1. 最近发生了什么新事实？
2. 哪些关于自己的判断被行动证实或推翻？
3. 当前阶段的优先事项、约束或取舍规则有没有变化？

这样填写出来的内容会持续服务于目标设定、行动安排、决策记录、AI 身份卡和上下文包，而不是一份写完后不再使用的静态自我介绍。

## 七、最小可用填写清单

如果时间有限，先完成以下内容：

- 当前身份：岗位、主要角色、当前职责；
- 人生阶段：当前阶段、当前优先事项、阶段诉求；
- 现实情况：每周可投入时间、最重要的约束、风险偏好；
- 重要经历：至少 3 条；
- 能力与证据：至少 3 项，每项有具体证据；
- 核心价值：至少 3 条，并写出一条冲突时的取舍规则；
- 待验证假设：至少 1 条，并写出验证方法。

先形成一个可用版本，再通过每周行动和复盘逐步补充，比等待“想清楚后一次填写完整”更有效。
