# 我的资源：分类与运营

## 使用流程

1. 在资源账本新增或编辑资源，选择六类资本、重要性、可用状态与适用场景，填写已知存量、投入、产出和边界。未知信息保持空白或待确认。
2. 安排使用、获取或维护任务，也可关联已有任务；已有未完成任务时从“继续任务”推进。
3. 完成任务后保存实际结果和下次调整。每日协同的 AI 任务须先验收并确认回写。
4. 打开“评估更新”，填写该资源实际投入、产出与可用情况，手动确认存量、状态、下一步及可选下次检查日期。
5. 查看评估历史，安排下一轮任务。多条资源关联同一任务时共用复盘，各自确认资源更新。

六类按身心、时间、财务、实物、知识、关系分组；要素由分类确定。到期检查优先，其次待获取或不可用，再按重要性和名称排序。检查日期使用上海日期，只在本页显示待处理，不发送提醒。

## AI 与兼容

AI 分类和资源生成先预览资料、生成可编辑建议，再手动确认。旧资源及旧待选草稿缺少六类时显示“待分类”，不会自动覆盖内容。选择确定的六类后自动关联要素。知识资源记录资料与方法，个人能力在“我的能力”维护。

本次不新增数据库表，使用已有资源标签 JSON、任务来源、行动复盘、策略版本与操作回执，无需 SQLite 或 D1 结构迁移。完整备份、同步及板块备份沿用既有机制；旧账本缺少新字段时补默认值，原要素、内容和历史保留。API key 不进入资源账本或备份。

配置与评估均原子保存。旧版本修改会拒绝并提示重新打开；同一资源、任务复盘版本只确认一次。完成任务不会自动扣减或增加存量，也不会自动判定可用。
